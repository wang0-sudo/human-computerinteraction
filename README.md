# 空气慧行：人机交互项目网站

[打开项目网站](https://wang0-sudo.github.io/human-computerinteraction/)

网站正文直接展示以下内容：

- 团队介绍与贡献说明。
- 项目方案：背景、核心问题、研究价值、移动应用适用性与可行范围。
- 数据收集计划：4 位学生的招募情境、实施步骤与分析方法。
- 完整访谈脚本：开场、3 个主题共 15 个主问题及追问、结束语。
- 完整调查问卷：21 道题的题型与选项。
- 研究伦理、隐私与可访问性。

这是一个使用 HTML、CSS 和 JavaScript 的静态前端网站。直接打开 `index.html` 即可预览，无需安装依赖。GitHub Pages 从 `main` 分支根目录发布。

访谈与问卷依据《P2_Planning_Data_Collection_AirAware》整理。页面展示研究方案，不将示例数据当作已完成的实际调查结果。
